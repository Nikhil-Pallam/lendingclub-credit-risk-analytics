# Data

Raw and processed data files are **not included** in this repository due to size — the accepted-loans dataset alone exceeds 250MB uncompressed, and the rejected-loans dataset exceeds 1.5GB. GitHub is not well-suited to hosting files this large, and it's standard practice to keep large datasets out of version control.

## Source

This project uses the **LendingClub Loan Data** dataset, publicly available on Kaggle:

**[https://www.kaggle.com/datasets/wordsforthewise/lending-club](https://www.kaggle.com/datasets/wordsforthewise/lending-club)**

Download the following two files (requires a free Kaggle account):
- `accepted_2007_to_2018Q4.csv.gz`
- `rejected_2007_to_2018Q4.csv.gz`

## Reproducing the cleaned datasets

The cleaned, feature-engineered datasets used throughout this project (`accepted_final.csv` and `rejected_final.csv`) are generated by running the notebook at `notebooks/LendingClub_Credit_Risk_Analysis.ipynb` top to bottom against the two raw files above.

The notebook documents every cleaning and filtering decision in detail — including the date-range scoping, missing-value handling, and outlier treatment — so the full reasoning behind each transformation is visible alongside the code itself.

## Expected shapes after cleaning

For verification purposes, the cleaned datasets should have the following dimensions:

| File | Rows | Columns |
|---|---|---|
| `accepted_final.csv` | 1,115,803 | 40 |
| `rejected_final.csv` | 24,191,792 | 11 |

If your reproduced files differ significantly from these counts, double-check that both raw files downloaded completely (large file downloads can sometimes truncate) before re-running the notebook.
